# 12306 车票候补系统（基础版）

这是一个使用 C 语言和**链式队列**实现的命令行候补订单演示程序。队列遵循先进先出（FIFO）：先提交的候补订单优先处理。

## 功能

- 新增候补订单，记录订单号、旅客姓名、身份证号和所需票数。
- 输入本次释放的余票数，从队头开始处理订单。
- 只有余票足以满足队头订单时才完成订单并出队；余票不足时保留该订单，继续等待。
- 查看当前候补队列。
- 退出时释放队列节点占用的内存。

订单号由程序依次生成。为保持先来先服务，若剩余余票无法满足队头订单，程序不会跳过该订单去处理后面的订单。

## 编译与运行

需要支持 C99 或更新标准的 C 编译器。

```bash
gcc -std=c99 -Wall -Wextra -pedantic wait_ticket.c -o wait_ticket
./wait_ticket
```

Windows 下可使用：

```bash
gcc -std=c99 -Wall -Wextra -pedantic wait_ticket.c -o wait_ticket.exe
wait_ticket.exe
```

## 队列实现说明

每个候补订单是一个链表节点。队列维护 `front`（队头）、`rear`（队尾）和订单数：

- `enqueue`：在队尾插入新订单，时间复杂度 O(1)。
- `dequeue`：移除并返回队头订单，时间复杂度 O(1)。
- 查看队列：从队头沿 `next` 指针遍历，时间复杂度 O(n)。

## 菜单

```text
1. 新增候补订单
2. 释放余票并处理候补
3. 查看候补队列
0. 退出程序
```

本项目是数据结构课程用的本地模拟程序，不连接铁路售票系统，也不提交真实购票请求。
